# Changelog

All notable changes to LedgerForce are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project will adhere to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) from its first
release.

> **How this file is maintained.** During Sprint 0 the `Unreleased` section is maintained by
> hand. From the first release onward it is **generated by release-please from Conventional
> Commits** (`feat(ar): batch billing preview [T-0057]`, `fix(ledger): …`); `wip(T-NNNN): …`
> checkpoint commits are squashed on merge and never appear here (design §10.7, ADR-0011).
> This is the **product** log. What each agent session did is in the operational run logs under
> `.agent/runs/`; why things were decided is in `Docs/decisions/decision-log.md` and `Docs/adr/`.
> See [`Docs/decisions/README.md`](Docs/decisions/README.md).

## [Unreleased]

### Added

- **Agent framework (Sprint 0):** canonical `AGENTS.md` with `CLAUDE.md` import; human-owned
  `.agent/config.yaml`; repo-resident state (`.agent/state.json`, `.agent/HANDOVER.md`, task
  leases) so claude or codex can resume any task from a checkout (ADR-0011).
- **Skills and sub-agent roles** under `.claude/skills/` and `.claude/agents/` (resume,
  claim-task, research, tdd-cycle, checkpoint, verify, evidence, write-adr, log-decision,
  golden-posting, cross-review, handover, run-log, new-task-card, migration, ui-screen).
- **Conductor failover loop** in `scripts/agent/` (zero-dependency Node.js): claim, lease,
  heartbeat, quota/credit failure detection, failover claude → codex on the same branch from
  the last green checkpoint, blocked after 3 attempts; with tests.
- **Architecture Decision Records** `Docs/adr/` — template, process README and index, seed
  ADRs 0001–0010 from design §10.6 and Sprint 0 ADRs 0011–0015.
- **Decision log** and decision-system guide (`Docs/decisions/`).
- **Research pack** (`Docs/research/RQ-*.md`) resolving Sprint 0 unknowns before build.
- **Backlog** of task cards generated from the design's use cases (`.agent/backlog/`).
- **Use-case specs** and success-scenario register (`Docs/specs/`).
- **Golden postings draft** (`Docs/accounting/postings.md`) for the design §3.8 standard events —
  draft for product-owner approval.
- **Database test harness:** Testcontainers (PostgreSQL 17) with a local PostgreSQL fallback
  when Docker is unavailable (ADR-0013).
- **Playwright evidence harness** writing screenshots to `.agent/evidence/<task>/` (ADR-0015).
- **UI principles**, design tokens and mockups (`Docs/ui/`).
- **GitHub templates:** pull request template mirroring the definition of done, human-gate issue
  template, label catalogue (`.github/`).
