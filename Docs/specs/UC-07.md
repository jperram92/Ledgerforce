## Actors / roles
Payroll Officer, second releaser, payroll provider

## Preconditions
- Payroll provider connected (Phase 1).
- Employee parties with verified bank details.

## Trigger
Payroll Officer imports a finalised pay run.

## Main flow
1. Import pay run (idempotent by pay-run id).
2. Payroll journal posts (GP-010).
3. Net-pay ABA batch created for release by a second user (GP-011 on confirmation).
4. Super and PAYG liabilities show in payables summary.

## Alternate and failure flows
- A1 Duplicate import → rejected as duplicate.
- A2 Officer releases own batch → denied.

## Business rules
- D5 payroll by integration; §3.8 rows 8–9; §6.5 rule 1.
