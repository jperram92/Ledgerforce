## Actors / roles
Finance Admin (author), second Finance Admin/Owner (activator)

## Preconditions
- Rules Studio enabled (Phase 1).

## Trigger
Finance Admin authors rule deposit-on-closed-won (§4.5).

## Main flow
1. Author writes the rule in the guided form (YAML).
2. Tests against three sample Opportunities; each preview balances.
3. Second user activates.
4. Next qualifying Closed Won produces the deposit journal (GP-014) tagged with rule id and version.

## Alternate and failure flows
- A1 Unbalanced test case → activation refused.
- A2 Author activates own rule → denied.
- A3 Rule line on control account without party → refused.

## Business rules
- §4.5 rule guarantees; §6.5 rule 5.
