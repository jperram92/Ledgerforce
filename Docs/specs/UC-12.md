## Actors / roles
Sales user (standard Salesforce access, no LedgerForce login)

## Preconditions
- Package installed; write-back running; user has the LF read-only permission set.

## Trigger
Sales rep opens an Account record page.

## Main flow
1. LWC reads mirror fields and LF_Invoice__c records.
2. Shows balance due, overdue amount, last payment date and five most recent invoices.

## Alternate and failure flows
- A1 No invoices → empty state.
- A2 User edits a mirror field → validation rule blocks.

## Business rules
- §5.4, §5.5 read-only mirror.

## Data touched (LedgerForce)
none in LedgerForce (reads Salesforce mirrors)

## Salesforce fields touched
Read: Account.LF_Balance_Due__c, LF_Overdue_Amount__c, LF_Credit_Status__c, LF_Last_Payment_Date__c; LF_Invoice__c.

## Postings produced
- None.

## Security / SoD checks
- Mirror objects read-only except integration user; no LF login.

### SS-UC12-01 — Component renders balance, overdue, last payment, 5 invoices
- Phase: MVP · Layer: **unit** · Screenshot evidence: no · Task(s): T-0072
