## Actors / roles
AP Clerk (maker), Approver/Owner (releaser, step-up MFA), bank, suppliers

## Preconditions
- 12 approved bills due this week.
- Suppliers have verified bank details.
- Operating bank account with ABA user id/APCA number.

## Trigger
AP Clerk creates a payment batch.

## Main flow
1. System proposes due bills; excludes suppliers whose bank details changed < 24 h, with reason.
2. A different user releases the batch with step-up MFA (two releasers above $10,000).
3. ABA file produced for upload.
4. Remittance advices emailed to supplier remittance contacts.
5. On bank confirmation the batch posts (GP-009) and allocates to the bills.

## Alternate and failure flows
- A1 Creator tries to release → denied.
- A2 No step-up → step_up_required.
- A3 Bank rejects a line → that payment is cancelled, bill re-opened.

### SS-UC06-01 — Batch created from 12 due bills
- Phase: MVP · Layer: **db-integration** · Screenshot evidence: no · Task(s): T-0054
- **Given** 12 approved bills due this week
- **When** the AP Clerk creates a batch
- **Then** the batch contains 12 payments totalling the bills' open amounts

### SS-UC06-02 — Creator cannot release own batch
- Phase: MVP · Layer: **db-integration** · Screenshot evidence: no · Task(s): T-0054, T-0015
- **Given** the SS-UC06-01 batch created by user A
- **When** user A releases it
- **Then** release is denied with SOD_BATCH_SELF_RELEASE

### SS-UC06-03 — Release requires step-up MFA
- Phase: MVP · Layer: **db-integration** · Screenshot evidence: no · Task(s): T-0054, T-0013
- **Given** user B without a fresh step-up
- **When** B releases the batch
- **Then** the response is step_up_required; after step-up the release succeeds

### SS-UC06-04 — Batch over $10,000 needs two releasers
- Phase: MVP · Layer: **db-integration** · Screenshot evidence: no · Task(s): T-0054
- **Given** a batch totalling $25,000
- **When** one releaser approves
- **Then** status is Partially released; a second distinct releaser completes it

### SS-UC06-05 — Recently changed bank details excluded with reason
- Phase: MVP · Layer: **db-integration** · Screenshot evidence: no · Task(s): T-0054, T-0053
- **Given** one supplier whose bank details were verified 3 hours ago
- **When** the batch is created
- **Then** that supplier's bill is excluded with reason BANK_DETAILS_COOLING_OFF
