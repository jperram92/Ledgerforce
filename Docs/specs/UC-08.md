## Actors / roles
Accountant, AR/AP Clerk

## Preconditions
- Bank account set up; statement file available (CSV, OFX or CAMT.053).

## Trigger
Statement import.

## Main flow
1. Import and normalise lines; detect duplicates.
2. Exact matches (amount + reference) auto-match.
3. Rule matches are suggested.
4. Remaining lines can be created as transactions through the engine.
5. Reconciliation report shows statement balance = book balance.

## Alternate and failure flows
- A1 Duplicate file → no duplicate lines.
- A2 Unmatched line left → report lists it as unreconciled.
