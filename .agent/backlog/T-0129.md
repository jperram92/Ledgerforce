# T-0129 — Daily overdue-reminder job in the worker and per-party reminder pause

## Goal
T-0068 built `runOverdueReminders` (AR) and the `email.reminder_queued` outbox handler (email). This card wires them up for production:
- a daily pg-boss schedule in apps/worker that runs `runOverdueReminders` for each company in its own tenant transaction, using the company's local date;
- `reminderEmailHandler` registered in the worker's handler registry;
- seeding of the default schedule at company setup;
- UC-04's "AR Clerk can pause reminders per party (audited)".

## Acceptance criteria
- [ ] AC-1: The worker registers `email.reminder_queued` and a daily schedule; a test with the pg-boss TestClock runs it once per day per company (no sleeps).
- [ ] AC-2: A paused party gets no reminder; pausing and resuming are audited and need the AR Clerk permission.
- [ ] AC-3: New companies get the default reminder schedule (step 1 at 7 days).

## Open questions
- [ ] Which time zone defines "the run date" for a company: company setting or tenant default (design §3.5 periods use the company's)? Research before building.
