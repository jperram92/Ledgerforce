# T-0142 — API security headers, strict CORS and rate limits (split from T-0097)

## Goal
Supersedes T-0097 (part). Every API response carries the OWASP REST security headers, the API
never grants cross-origin access, and authentication plus every state-changing route is rate
limited per client address with `429` and `Retry-After` (design §6.9, apps/api AGENTS.md).
Decision: [ADR-0054](../../Docs/adr/0054-api-security-headers-and-rate-limits.md) (security,
Proposed — human gate). Research: [RQ-0141](../../Docs/research/RQ-0141-api-security-headers-and-rate-limits.md).

## Acceptance criteria (each maps to a test)
- AC-1 Given any API route (public health, authenticated, 404, 401) When it answers Then it sends
  `Cache-Control: no-store`, `Content-Security-Policy: default-src 'none'; frame-ancestors 'none'`,
  `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`,
  `Cross-Origin-Resource-Policy: same-origin`, and no `X-Powered-By`; `Strict-Transport-Security`
  only when the public URL is https → `apps/api/src/security/security-headers.db.test.ts`
- AC-2 Given a preflight or a request from another origin When the API answers Then no
  `Access-Control-Allow-*` header is sent (strict CORS: cross-origin access is never granted)
  → same file (regression guard: Nest's default is already strict; see RED notes)
- AC-3 Given the auth limit N When one client address makes N+1 login requests within the window
  Then the last answers `429 {error:'rate_limited'}` with an integer `Retry-After`; another address
  is unaffected; after the window the client is allowed again → `apps/api/src/security/rate-limit.db.test.ts`
- AC-4 Given the mutating limit When a client exceeds it with POST/PUT/PATCH/DELETE Then `429`
  before any handler or database work runs; GET reads are not limited; webhooks have their own
  class → same file, plus unit tests `apps/api/src/security/rate-limit.test.ts`
- AC-5 Production configuration always enables the limits with the ADR-0054 defaults, reads
  `LF_TRUST_PROXY_HOPS` (0–5, default 0) and enables HSTS for an https public URL →
  `apps/api/src/config.test.ts`; compose passes `LF_TRUST_PROXY_HOPS` → `infra/test/install-contract.test.ts`
