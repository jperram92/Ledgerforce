# T-0147 — Daily overdue-reminder run for every company (split from T-0129)

## Goal
A daily pg-boss schedule runs `runOverdueReminders` once per company per day in the company's
tenant transaction. The run date is the date in the tenant's `report_timezone` (RQ-0144). The
worker also registers `reminderEmailHandler` for `email.reminder_queued`.

## Blocked
This needs a way to reach every tenant from a process that has no tenant context. That is a
change to the tenant boundary, so it needs a **security** ADR: ADR-0062 (Proposed), a human
gate. The options and a recommendation are in the ADR and in HANDOVER's open questions.

## Acceptance criteria
- [x] AC-1: Accept ADR-0062, then implement the chosen primitive or enqueuer with RLS tests that
      prove it reveals nothing but what the ADR allows.
- [x] AC-2: The worker registers `email.reminder_queued` and the daily schedule. A test with a
      controlled clock (no sleeps) runs it once per day per company. A re-run on the same day
      queues nothing (SS-UC04-03).
- [x] AC-3: The run date follows the tenant's `report_timezone` (tests around midnight
      Sydney/UTC).
