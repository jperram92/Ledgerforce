# T-0135 — Credit-note API routes with SoD and the small-team exception

## Goal
Expose `@ledgerforce/ar` credit notes (T-0045) through apps/api: create (`ar.credit_note.create`,
`@SoD('credit_note.create')`), approve (`ar.credit_note.approve`, `@SoD('credit_note.approve')`
with the recorded amount), post, preview, allocate and the adjustment-note document. The module
refuses the creator's approval above the threshold and fails closed (DL-0323); the API is where a
small-team exception (ADR-0026, design §6.5) is requested and recorded, after which the module is
called with that recorded exception. The database guard (migration 0040) already allows small-team
mode.

## Acceptance criteria (each maps to a test + SS id)
- [ ] **SS-UC11-06** (db-integration, API layer) The AR Clerk who created a credit note above the
  threshold gets SOD_CREDIT_NOTE_SELF_APPROVAL from the approve route; in small-team mode with a
  recorded exception reason the approval succeeds and the exception is listed in the weekly report.
- [ ] Routes are RBAC-checked (ar.credit_note.create / approve) and tenant-isolated.
