# T-0117 — Promote period-end accounts to system roles (additive role binding)

## Goal
Bind AR_ECL_ALLOWANCE, PREPAYMENTS, ACCUM_DEPRECIATION, DEPRECIATION_EXPENSE, ACCRUED_EXPENSES, SGC_PAYABLE and PRIOR_PERIOD_ADJUSTMENTS as system roles (design §3.2, §3.10) so period-end jobs resolve them by role, not by template setting.

## Context
- T-0116 bound them through template `suggestedSettings` because `app.account_system_role.role` has an inline CHECK list that cannot be widened without `DROP CONSTRAINT`, which the forward-only migration gate forbids.
- Needs a data-model ADR choosing an additive design (e.g. a second role-binding table with the same RLS, type rules and assert trigger, or a NOT VALID replacement constraint strategy) — data-model change, ADR required (design §10.6).
