# T-0145 — BAS calculation-worksheet labels G4 and G14

## Goal
The accountant-reviewer persona review (DL-0280, MINOR "Chart (bank fees INP)") asks for purchase-side
`INP` → G11 **+ G14** and sales-side `INP` → **G4**. T-0035 maps INP purchases → G11 (never G13) and
INP sales → G1. Those are the lodged BAS-form labels, and they are correct. G4 and G14 are GST
*calculation-worksheet* labels. Migration 0036's `app.bas_label_map.label` CHECK and `BAS_LABELS`
list only form labels, and the runner refuses `DROP CONSTRAINT`. T-0121 therefore split this part
off (DL-0341). Design §3.6.

## Scope
- Decide the forward-only shape at claim (skill `migration`, DL entry). Options: a worksheet-label
  column or table next to `app.bas_label_map` with the same effective dating, RLS ENABLE + FORCE and
  guards, or a new label column with a wider CHECK, backfilled, with the old one marked deprecated
  (ADR if it changes the data model).
- AU template (new version per DL-0340): INP sales → G4; INP purchases → G14 (and FRE purchases
  → G14 where the review confirms it).
- The tax report exposes worksheet labels separately from the form labels; Simpler BAS is
  unchanged.
