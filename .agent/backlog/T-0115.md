# T-0115 — Nightly posting-profile gap check job

## Goal
Run the T-0039 gap check (`postingProfileGapCheck`, packages/modules/products) nightly for every
company of every tenant and surface the result where people see it (design §4.4: "A gap check
runs in the wizard and nightly"). Split from T-0039 step 3 (DL-0261): apps/worker has no
scheduled-job mechanism yet, and the gap check itself (a read-only report) is complete.
