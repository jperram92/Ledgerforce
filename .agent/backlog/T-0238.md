# T-0238 — Unattended OAuth grants for the bills mailbox

## Goal
Split from T-0216 (DL-0930, RQ-0187 F2/F3). Delegated grants (T-0216) die when the signing-in
user leaves or the grant is revoked. Some operators prefer an unattended service principal:
Microsoft 365 client credentials (`https://outlook.office365.com/.default`, IMAP.AccessAsApp,
`New-ServicePrincipal` + `Add-MailboxPermission`) and Google Workspace service accounts with
domain-wide delegation (JWT bearer grant, RS256 with node:crypto).

## Acceptance criteria
- [ ] AC-1 (unit) client-credentials token request and JWT-bearer assertion against recorded
  responses; XOAUTH2 with the resulting token against the fake IMAP server
- [ ] AC-2 (db) a mailbox row with auth_method for the unattended grant; client secret / private
  key handling decided in an ADR (install configuration vs sealed per company)
- [ ] AC-3 (docs) operator runbook for the Exchange PowerShell and Workspace admin steps
