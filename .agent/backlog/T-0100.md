## Acceptance criteria (each maps to a test + SS id)
- [ ] **SS-UC04-05** (contract) — Salesforce Task logged for the Account owner. *Given* an invoice 7 days overdue; *when* the reminder schedule runs; *then* a Task is created on the Account assigned to its owner.
- [ ] **SS-UC04-06** (db-integration) — Credit hold at 30 days blocks auto-approve. *Given* an invoice 30 days overdue; *when* the schedule runs and a new Closed Won arrives; *then* the party is on credit hold, the new invoice stays Draft, and Salesforce shows the hold.
- [ ] **SS-UC07-01** (golden) — Pay run import posts GP-010. *Given* a finalised pay run (gross 10,000, PAYG 2,000, super 1,200); *when* it is imported; *then* the journal equals GP-010.
- [ ] **SS-UC07-02** (golden) — Net-pay batch released by second user posts GP-011. *Given* the net-pay batch from SS-UC07-01; *when* a second user releases it and the bank confirms; *then* the journal equals GP-011.
- [ ] **SS-UC07-03** (db-integration) — Liabilities in payables summary. *Given* SS-UC07-01 posted; *when* the payables summary is opened; *then* PAYG 2,000.00 and super 1,200.00 are listed.
- [ ] **SS-UC07-04** (db-integration) — Duplicate pay-run import is idempotent. *Given* a pay run already imported; *when* it is imported again; *then* no second journal exists.
- [ ] **SS-UC07-05** (db-integration) — Payroll Officer cannot release own net-pay batch. *Given* a batch created by the Payroll Officer; *when* they release it; *then* release is denied.
- [ ] **SS-UC09-01** (unit) — Three sample previews balance. *Given* the deposit rule and three sample Opportunities; *when* the Finance Admin tests the rule; *then* three balanced previews are returned.
- [ ] **SS-UC09-02** (unit) — Unbalanced rule cannot be activated. *Given* a rule whose test case does not balance; *when* activation is requested; *then* activation is refused.
- [ ] **SS-UC09-03** (db-integration) — Author cannot activate own rule. *Given* a rule authored by user A; *when* A activates it; *then* activation is denied.
- [ ] **SS-UC09-04** (golden) — Activated rule produces GP-014 tagged with rule id and version. *Given* the rule activated by user B; *when* a qualifying Closed Won (Amount 10,000, Deposit 30%) arrives; *then* the journal equals GP-014 with rule_id deposit-on-closed-won and version 3.
- [ ] **SS-UC09-05** (unit) — Rule cannot hit a control account without a party. *Given* a rule line on AR_CONTROL without party; *when* the rule is validated; *then* validation fails.
