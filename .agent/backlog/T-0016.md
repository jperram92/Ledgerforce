# T-0016 — User lifecycle (joiner/mover/leaver) and scoped API tokens

## Goal
Invite → role → MFA before access; role change by Owner/Finance Admin with SoD check; leaver disabled never deleted, sessions/tokens revoked; hashed scoped API tokens.

## Report (claude, 2026-10-25, parallel round 5)

**Built** (branch `feat/T-0016-user-lifecycle`, from cef9f8f):
- Research RQ-0031 (resolved), ADR-0027 (security, **Proposed** — human gate), DL-0141..DL-0145.
- Migration `0022_auth_user_lifecycle.sql`: `app.app_user` lifecycle columns (invited_by,
  disabled_at/by, disable_reason, successor_user_id) + guard trigger; leaver trigger
  `app_user_offboard` (revokes sessions, API tokens and role grants, bumps the epoch, audits
  `user.disabled`; nothing deleted); `app.api_token` (RLS ENABLE+FORCE, tenant_isolation,
  SELECT/INSERT + column UPDATE for lf_app, SHA-256 only, mandatory ≤366-day expiry, insert and
  update/delete guards); mirrors `app.permission_known` / `app.token_scope_allowed`;
  `app.approval_assignee` (successor chain); `user_role` trigger refusing self-grants and grants
  to disabled users; `audit.audit_log.api_token_id`.
- API: `POST /users` (invite), `GET /users/:id`, `POST /users/:id/offboard`; `/api-tokens` issue
  (fresh step-up, secret once, no-store), list, revoke; `/users/:id/api-tokens` list/revoke for
  administrators; bearer-token resolver; interceptor (scopes ∩ role permissions, tokens never
  satisfy step-up, audit attribution); self-grant refusal (403, audited) and 409 for grants to
  disabled users; OIDC joiner gate (MFA before first access for MFA roles) + `user.joined`.

**Tests** (all named with SS ids): `packages/db/src/user-lifecycle.db.test.ts` (14),
`apps/api/src/tokens/tokens.scope.db.test.ts` (9), `apps/api/src/users/users.lifecycle.db.test.ts`
(4), new SS-PLAT-71 describe in `apps/api/src/auth/oidc.db.test.ts` (3). RED captured first for
each (missing schema/routes; self-grant reached the DB as 500; no enrolment gate).

**Mutation check** (12 hand mutants, each killed by the named suite): M1 token scopes ignored;
M2 cookie+bearer accepted; M3 expiry not checked; M4 leaver trigger skips tokens; M5 DB allows
self-grant; M6 API allows self-offboard; M7 joiner gate removed; M8 forbidden scopes not checked
in API; M9 issue without held permission; M10 disabled user re-activated; M11 API self-grant
check removed; M12 token audit attribution dropped. Script:
scratchpad `t0016/mutate.py`. Known equivalent mutant (not run): dropping the `status = 'active'`
check in token verification is masked by the leaver trigger revoking the token; it is kept as
defence in depth for a token committed concurrently with an offboard (DL-0142).
