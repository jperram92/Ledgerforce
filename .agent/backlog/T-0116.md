# T-0116 — Sales invoice API routes and Finance-Admin-only auto-approve setting

## Goal
Expose the T-0040 sales-invoice module (`packages/modules/ar`) through apps/api: create draft,
approve, post, preview ("show me the journal"), read, and read/set the auto-approve setting.
Split from T-0040 (DL-0297): T-0040 delivered the module, tables and golden-proved posting; the
HTTP surface (idempotency keys, RBAC permission for approval, audit, OpenAPI) is a public-API
change (design §10.6 → ADR) and is needed by T-0083 (UI).

## Context (design refs)
- Design: §4.3, §6.4 (AR Clerk creates/sends invoices; Approver), UC-01 "Auto-approve is a tenant
  setting changeable only by Finance Admin; audited"; apps/api AGENTS.md (idempotency, decimal
  strings, audit every mutation).
- Module: `packages/modules/ar/src/sales-invoices.ts` (T-0040, RQ-0104, DL-0294).
- RBAC: `ar.invoice.create`/`ar.invoice.send` exist; an approve permission does not yet.

## Open questions (→ research before start)
- Which permission guards approval (new `ar.invoice.approve`? for which roles)? Public API +
  RBAC catalogue change → ADR.
- Wire `invoiceOutboxNotifier` and `ledgerOutbox` from the API's pg-boss runtime.

## Acceptance criteria (each maps to a test + SS id)

  for every role but Finance Admin/Owner and is audited.
