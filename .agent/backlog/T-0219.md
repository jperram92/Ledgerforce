# T-0219 — No-recipient security notices are visible

## Goal
A supplier bank-detail notice (0025) whose supplier has no remittance contact is written as
`no_recipient` and is never sent (T-0197). Nobody is told. T-0209 lists only `failed` notices
(RQ-0179 follow-up). Show `no_recipient` notices on the Failed security notices screen with
"no address on record", a link to the supplier's contacts, and decide (research) whether adding a
contact later should create a fresh notice to that contact.

## Acceptance criteria
- [ ] AC-1 (db/API) no-recipient notices are listed for `security_notices.read` holders of the tenant only
- [ ] AC-2 (e2e) the screen shows them with a link to the supplier, with screenshots
