# T-0207 — Cancel a requested bank refund

## Goal
T-0190 (DL-0770) cancels only Stripe refund documents, so `POST /ar/refunds/:id/cancel` answers
422 `NOT_CANCELLABLE` for a bank refund. A requested bank refund that the customer no longer
wants keeps counting as requested in `customerCredit`. Allow the same route to cancel a requested
`bank_batch` refund when no live payment batch line pays it. The 0055 guard already refuses that
case in the database. Show Cancel in the refund region for a requested bank refund.

## Acceptance criteria
- [x] AC-1 (db) a requested bank refund outside any live batch is cancelled and stops counting as
      requested; one in a live batch is refused (`NOT_CANCELLABLE`, and the 0055 guard as well)
- [x] AC-2 (api-db) the route works for both methods; permission `ar.refund.create`; another
      tenant's refund is 404
- [x] AC-3 (e2e) the refund region offers Cancel for a requested bank refund
