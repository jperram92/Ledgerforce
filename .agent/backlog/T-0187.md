# T-0187 — Posting-profile matrix over HTTP

## Goal
Split from T-0177 (DL-0650). The posting-profile screen (T-0188, IA S13, wizard step 7) needs to read
the party × product matrix and fill a gap. No route exists (RQ-0162). This card adds:
- the module read `profileMatrix` in `@ledgerforce/products`, which resolves every cell by the same rule as `resolvePosting`;
- `GET /posting-profiles/matrix` (settings.read);
- `PUT /posting-profiles/overrides` (settings.chart.manage, Idempotency-Key, audited when it changes something).

The routes are defined in ADR-0082.

## Context (design refs)
- Design §4.4; `packages/modules/products/src/matrix.ts` (T-0039, DL-0267); ADR-0082; RQ-0162.

## Acceptance criteria (each maps to a test + SS id)
