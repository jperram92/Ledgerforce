# T-0023 — Periods, close status matrix and lock-date policy

## Goal
Fiscal periods with statuses Open/AR locked/AP locked/Soft closed/Hard locked, a source-type × status matrix, override permission, and tenant policy reject | post-to-first-open-date-with-note.

## Context (design refs)

- Specs: [UC-01](../../Docs/specs/UC-01.md), [UC-03](../../Docs/specs/UC-03.md), [UC-05](../../Docs/specs/UC-05.md), [UC-08](../../Docs/specs/UC-08.md), [UC-10](../../Docs/specs/UC-10.md) · Register: [success-scenarios.md](../../Docs/specs/success-scenarios.md)

## Acceptance criteria (each maps to a test + SS id)
- [ ] **SS-UC01-08** (db-integration) — Closed Won dated in a hard-locked period follows lock policy. *Given* October hard-locked and an Opportunity closed 2026-10-30; *when* Closed Won fires under policy "reject" and again under "post to first open date"; *then* "reject" → Sync issue with PERIOD_LOCKED, no draft; "first open date" → invoice dated 2026-11-01 with a note.
- [ ] **SS-UC03-09** (db-integration) — Late payout in an AR-locked period follows the period matrix. *Given* November AR-locked; *when* a payout dated 2026-11-30 is processed; *then* the posting is allowed/denied exactly as the approved period matrix states for source type payments.stripe.payout.
- [ ] **SS-UC05-07** (db-integration) — Bill in AP-locked period rejected. *Given* October AP-locked; *when* a bill dated 2026-10-20 is posted without override; *then* posting is rejected with PERIOD_LOCKED.
- [ ] **SS-UC08-07** (db-integration) — Reconciled lines locked after hard lock. *Given* November hard-locked; *when* a user unmatches a November line; *then* the action is rejected.
- [ ] **SS-UC10-02** (db-integration) — AR lock blocks AR posting except with override. *Given* October AR-locked; *when* an AR Clerk posts an October invoice, then an override user does; *then* the first is rejected; the second succeeds and is audited; AP bills still post.
- [ ] **SS-UC10-03** (db-integration) — AP lock allows journals only. *Given* October AP-locked; *when* a bill, an invoice and a manual journal are posted for October; *then* bill and invoice rejected, journal accepted.
- [ ] **SS-UC10-04** (db-integration) — Soft close: Finance Admin override only. *Given* October soft-closed; *when* an Accountant and a Finance Admin with override post a journal; *then* the Accountant is rejected; the Finance Admin succeeds.
- [ ] **SS-UC10-05** (db-integration) — Hard lock rejects or redirects per policy. *Given* October hard-locked; *when* a document dated October is posted under each lock policy; *then* "reject" → PERIOD_LOCKED; "first open date" → dated 2026-11-01 with note.
- [ ] **SS-PLAT-06** (unit) — Period status matrix is enforced as data. *Given* every source type × period status; *when* posting is attempted with and without override; *then* allow/deny/override results equal the approved §3.5 matrix table.
