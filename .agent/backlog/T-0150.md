# T-0150 — Bank: journal preview for a transaction from a line (follow-up of T-0088/T-0149)

## Goal
Gap found while building T-0149 and T-0088 (DL-0482). **Journal preview (P4).** The
create-transaction screen posts without showing the journal first, because `@ledgerforce/bank`
has no preview for `createTransactionFromLine`. Add a module preview that runs the posting
engine's `preview` (validate and build, no writes) on the same command the real post uses, a
`POST /bank-rec/lines/:id/transaction/preview` route, and show the journal on the screen before
"Post transaction".

Re-scoped by DL-0530: the card was over the ~400-line limit, so **candidate suggestions** moved
to T-0160 and **large statement files** to T-0161 (research RQ-0151).

Posting behaviour: a transaction from a line is a manual journal of the user's own lines
(DL-0312, T-0029: manual journals post the lines as written, with no golden posting); the
preview adds no new posting behaviour and uses the same command builder as the post.

## Acceptance criteria (each maps to a test)
- [ ] AC-1: the preview returns the journal lines the post would write (decimal strings, bank
  line first, account names), refuses what the post refuses (UNBALANCED, CONTROL_ACCOUNT,
  ALREADY_MATCHED) and writes nothing. → `packages/modules/bank/src/matching.db.test.ts`
- [ ] AC-2: over HTTP: 200 with the preview (snake_case, decimal strings), 422 with the engine's
  code for a refused one, 403 without bank.reconcile, 404 for another company's line, and no
  journal, manual journal or match is written. → `apps/api/src/bank/bank-rec.db.test.ts`
- [ ] AC-3: the create-transaction screen shows the journal from the preview (Balanced) before
  "Post transaction", refreshes it when the account or amount changes, and explains a refused
  preview in plain words without offering to post. → `tests/e2e/web/bank-preview.spec.ts`

## Open questions
- None (no golden posting needed: DL-0312; route shape follows the opening-balance preview,
  POST without an idempotency key because it writes nothing).
