# T-0069 — Closed Won / Order activated → draft invoice (UC-01) with auto-approve

## Goal
Opportunity Closed Won (or Order activated — §11.2 default open) creates a draft invoice via template; auto-approve under threshold.

## Context (design refs)
- Design: UC-01, §4.3, §11.2 invoice trigger default (human).
- Specs: [UC-01](../../Docs/specs/UC-01.md) · Register: [success-scenarios.md](../../Docs/specs/success-scenarios.md)
- Depends on: T-0065 (Inbound mapping: Account/Contact/Product → Party/Product with idempotency); T-0040 (Sales invoice lifecycle: draft → approve → post); T-0067 (Write-back to Salesforce via sObject Collections from the outbox); T-0031 (Golden-posting test runner)

## Open questions (→ research before start)
- [ ] §11.2 invoice trigger default — implement both behind a setting, default Opportunity until decided.

## Acceptance criteria (each maps to a test + SS id)
- [ ] **SS-UC01-01** (db-integration) — Closed Won creates a draft invoice from the template. *Given* an Opportunity with 2 line items (Professional services $1,000, Subscription $250) on an Account with a Billing To contact; *when* the Opportunity moves to Closed Won; *then* exactly one Draft invoice exists with 2 lines mapped to the PROFESSIONAL_SERVICES and SUBSCRIPTION profiles and tax code GST.
- [ ] **SS-UC01-02** (e2e-playwright, screenshot evidence) — Salesforce shows "Draft" within 60 seconds. *Given* SS-UC01-01 has run against a scratch org; *when* 60 seconds elapse; *then* Opportunity.LF_Invoice_Status__c = "Draft" (screenshot of the Opportunity record).
- [ ] **SS-UC01-03** (golden) — Auto-approve under threshold posts GP-001 and emails. *Given* auto-approve on with threshold $2,000 and the SS-UC01-01 Opportunity; *when* the draft is created; *then* the invoice is posted with exactly the GP-001 journal, numbered INV-…, and one email is sent to the Billing To contact.
- [ ] **SS-UC01-04** (unit) — Above threshold stays Draft. *Given* auto-approve threshold $1,000 and a $1,375 invoice; *when* the draft is created; *then* status remains Draft and no journal is written.
- [ ] **SS-UC01-06** (unit) — Posting-profile gap flagged, not posted. *Given* a product profile × party profile combination with no revenue account; *when* Closed Won fires; *then* the draft carries a PROFILE_GAP warning, nothing posts, and the combination is listed by the gap check.
- [ ] **SS-UC01-07** (db-integration) — Duplicate CDC event is idempotent. *Given* the same CDC event (same record Id + commit number) delivered twice; *when* both are processed; *then* one draft invoice exists and the second event is logged as duplicate.
- [ ] **SS-UC01-08** (db-integration) — Closed Won dated in a hard-locked period follows lock policy. *Given* October hard-locked and an Opportunity closed 2026-10-30; *when* Closed Won fires under policy "reject" and again under "post to first open date"; *then* "reject" → Sync issue with PERIOD_LOCKED, no draft; "first open date" → invoice dated 2026-11-01 with a note.
