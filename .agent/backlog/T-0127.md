# T-0127 — Bills inbox transports: IMAP polling (self-host) and provider inbound webhooks (SaaS)

## Goal
Feed `ingestBillEmail` (T-0051) from a mailbox: an IMAP poller in the worker for self-hosted installs (credentials envelope-encrypted) and a signed inbound-webhook endpoint for the hosted SaaS.

## Context
- RQ-0111: IMAP polling is the self-host default; SMTP receiving is not offered; provider webhooks for SaaS.
- An IMAP client is a new runtime dependency (ADR); mailbox credentials are secrets (design §6.6, security ADR → human gate).

## Acceptance criteria
- [x] AC-1 A message placed in a test IMAP mailbox becomes one inbox item; re-polling adds nothing.
  → `packages/modules/ap/src/inbox-mailbox.db.test.ts`, `imap-client.test.ts`, `imap-client.tls.db.test.ts`, `apps/worker/src/inbox-poll-jobs.db.test.ts` (SS-PLAT-154..156)

  **Moved to T-0215** (split by transport, DL-0810); XOAUTH2 and the settings API/UI → T-0216.
