# T-0127 — Bills inbox transports: IMAP polling (self-host) and provider inbound webhooks (SaaS)

## Goal
Feed `ingestBillEmail` (T-0051) from a mailbox: an IMAP poller in the worker for self-hosted installs (credentials envelope-encrypted) and a signed inbound-webhook endpoint for the hosted SaaS.

## Context
- RQ-0098: IMAP polling is the self-host default; SMTP receiving is not offered; provider webhooks for SaaS.
- An IMAP client is a new runtime dependency (ADR); mailbox credentials are secrets (design §6.6, security ADR → human gate).

## Acceptance criteria
- [ ] AC-1 A message placed in a test IMAP mailbox becomes one inbox item; re-polling adds nothing.
- [ ] AC-2 A signed inbound webhook delivers one inbox item; an unsigned or replayed one is refused.
