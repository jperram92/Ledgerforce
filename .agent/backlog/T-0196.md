# T-0196 — Idempotency-Key on the weekly SoD acknowledgement

## Goal
RQ-0167 S8: `POST /sod/exceptions/weekly/acknowledge` is a mutating route without an
Idempotency-Key, against the apps/api rule. T-0186 fixed `POST /sod/settings` (ADR-0085). This
route has a web caller (`apps/web/src/admin/client.ts` `acknowledgeWeek`), so the client and the
route change together.

## Acceptance criteria
- [x] AC-1 (api-db) without a key: 400 `idempotency_key_required`, nothing written; with a key the behaviour is unchanged (201 new, 200 already acknowledged)
- [x] AC-2 (e2e) the control-exceptions screen sends a key; the existing spec stays green
