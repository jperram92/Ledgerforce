# T-0111 — LWC Account component: scratch-org e2e with screenshot

## Goal
Prove in a real scratch org what T-0072 proved offline: a sales user with the `LF_Read_Only`
permission set opens an Account with synced LedgerForce data and the `lfAccountSummary`
component shows balance due, overdue amount, last payment and the five most recent invoices.
Split from T-0072 (DL-0221): no Dev Hub or scratch org exists in the build environment yet
(RQ-0022, RQ-0045). Design §5.4, §8.2 UC-12.

- Component: `salesforce/force-app/main/default/lwc/lfAccountSummary` (T-0072).
- Specs: [UC-12](../../Docs/specs/UC-12.md) · Register: [success-scenarios.md](../../Docs/specs/success-scenarios.md)

  date mirror fields; multi-currency orgs (currency code on the fallback formatter).
