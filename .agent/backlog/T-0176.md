# T-0176 — Settings forms for the setup wizard's steps

## Goal
The T-0091 wizard screen shows what each step is missing, but several steps have no screen where
the setting can be entered: step 1 (legal name, ABN, base currency, fiscal year start), step 3 (GST
basis, BAS frequency, tax codes), step 4 (bank accounts with APCA user id and ABA user name), step
8 (invoice number series, billing format, branding colour, default payment terms, accepted payment
methods, Stripe settings) and the approval amounts of step 10 (SoD settings). Today the wizard says
plainly "there is no LedgerForce screen for this yet" (DL-0601). This card adds the screens, linked
from the wizard's "where" line, so a fresh tenant can finish setup without the API.

## Context (design refs)
- Design §4.1 (steps), §6.4–6.5 (who may change settings), IA S18/S19 (`Docs/ui/information-architecture.md`).
- Validators: `packages/modules/setup/src/wizard-validators.ts` (what each step needs).
- Split from T-0091 (DL-0601). Wizard screen: `apps/web/src/setup/WizardPage.tsx`.

## Open questions (→ research before start)
- Which of these settings already have HTTP routes (T-0158 added module-owned tax and ar settings;
  check `apps/api/src`)? Missing routes are public API changes and need an ADR (design §10.6).
- Likely too large for one session: split per step with `new-task-card` at claim.

## Scope after the split (DL-0640)
This card now covers steps 1 and 3 only. Step 4 (bank accounts) moved to T-0185; steps 8
(numbering and billing) and 10 (approval amounts) moved to T-0186. The original AC-1 and AC-2
apply to each card for its own steps.
