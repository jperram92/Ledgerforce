## Report (claude, 2026-10-25, branch feat/T-0053-bank-change-verification)

### What was built
- **RQ-0034** (resolved): the cooling-off starts at verification; the "previous remittance contact" is snapshotted when the change is requested; step-up is also proven in the database; requester ≠ verifier is enforced at COMMIT, with the small-team exception; the eligibility contract for T-0054.
- **Migration 0025** (`0025_parties_bank_detail_change.sql`):
  - `app.bank_detail_change`: requested → verified | rejected. `lf_app` has SELECT only. Writes go through the SECURITY DEFINER functions `app.bank_detail_change_request`, `…_verify` and `…_reject`, which check the SQL permission mirror, a fresh step-up session (≤ 300 s, MFA, own, live) and the out-of-band confirmation note.
  - A deferred constraint trigger enforces `SOD_BANK_DETAIL_SELF_VERIFY`. A self-verification passes only when small-team mode is on and an `app.sod_exception` row exists.
  - A guard on `app.party_bank_account`: new accounts start pending; an account becomes active only through a verified change; superseded and archived are final; one active account per party.
  - `app.bank_detail_settings`: cooling-off hours (default 24, 1–720), Owner only, audited, frozen per change.
  - `app.bank_detail_change_notice`: durable notices with masked details.
  - `app.party_payment_eligibility(uuid[])` returns `BANK_DETAILS_COOLING_OFF` or `NO_VERIFIED_BANK_DETAILS`.
- **parties module** `bank-detail-changes.ts`: `requestBankDetailChange`, `verifyBankDetailChange`, `rejectBankDetailChange`, `paymentEligibility`, `setBankDetailCoolingOff`, and the typed error `BankDetailChangeRefused`.
- **API** `BankDetailChangesController`:
  - `POST /parties/:partyId/bank-accounts` (request)
  - `POST /bank-detail-changes/:changeId/verify`
  - `POST /bank-detail-changes/:changeId/reject`

  Every route goes through `@RequirePermission`, step-up 300 s and `@SoD`. `createApi({ kms })` is optional; without it the request route answers 503.
- Decisions: ADR-0030 (security, Proposed) and DL-0156..DL-0160.
