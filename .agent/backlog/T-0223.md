# T-0223 — Bills inbox transport: SendGrid Inbound Parse (signed security policy, send_raw)

## Goal
SendGrid Inbound Parse posts the raw message (`send_raw`, field `email`) to `POST /webhooks/sendgrid/inbound`; authenticity by the signed security policy (ECDSA P-256 / SHA-256 over timestamp ‖ raw body, RQ-0181 S6) verified with the configured public key, ±300 s, constant-shape refusals; replay key and tenant routing reuse ADR-0099 (`app.inbound_webhook_receipt` provider `sendgrid`, recipient token from the JSON `envelope` through `app.bill_inbox_route()`).

## Acceptance criteria
- AC-1 A recorded `send_raw` POST with a valid signature to the company's inbound address delivers one inbox item; a redelivery adds nothing
- AC-2 Unsigned, wrongly signed, stale or replayed requests are refused before anything is parsed or stored
- AC-3 Several envelope recipients: only the ones at the inbound domain route; none resolvable → 406 without tenant detail
