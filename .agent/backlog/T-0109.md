# T-0109 — verify gate 9 writes evidence only for the task being verified

## Goal
`bash scripts/agent/verify.sh --task T-X` runs `pnpm test:e2e`, and the Playwright evidence fixture
writes screenshots and manifest entries for every spec's own task (T-0009, T-0106 …), not for T-X.
Every verify run therefore adds about 30 PNGs to `.agent/evidence/T-0009/`. They were committed in
the "verified → review" commits from T-0017 to T-0011 (DL-0098). They are genuine re-runs, so they
are kept (directive 6), but they are noise filed under the wrong task.

## Context (design refs)
- DL-0098; skill `evidence`; `scripts/agent/verify.sh` gate 9; `tests/e2e/fixtures`.

## Acceptance criteria (each maps to a test + SS id)
- [ ] (add an SS id before claiming) — a verify run for task X leaves `.agent/evidence/<Y>/` untouched for Y ≠ X
  (e.g. the evidence fixture writes to a temp dir unless `LF_TASK_ID` equals the spec's task, or gate 9 sets
  `LF_EVIDENCE_DRY_RUN=1`).

## Steps
- [ ] 1. Failing test (scripts/agent/test or a Playwright fixture unit test)
- [ ] 2. Fix fixture / gate
- [ ] 3. `bash scripts/agent/verify.sh` green (definition of done) [phase: verify]
- [ ] 4. Cross-provider review (`cross-review`) [phase: review]
- [ ] 5. Update register, decision log, run log, HANDOVER; release lease [phase: finish]

## Notes for the next agent
- Until this lands, after any verify run, move untracked `.agent/evidence/**` files of other tasks out of the
  tree and `git checkout` their manifests before committing (HANDOVER says so).
