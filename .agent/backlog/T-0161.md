# T-0161 — Bank: large statement files over HTTP (split from T-0150)

## Goal
Split from T-0150 (DL-0530). Statement import sends the file as base64 JSON and the API's JSON
body limit is Express's default 100 kB (about 75 kB of file), so a busy month's CSV is refused
with 413. Raise the limit for `POST /bank-rec/accounts/:id/statements` only, as recommended by
RQ-0151 (no new runtime dependency), and keep every other route at the default.

## Acceptance criteria (each maps to a test)
- [ ] AC-1: a CSV of about 1 MB (several thousand lines) imports over HTTP with 201 and the right
  line count. → `apps/api/src/bank/bank-rec.db.test.ts`
- [ ] AC-2: a body above the route's limit is refused with 413 and nothing is imported; another
  route still refuses a body over 100 kB with 413. → `apps/api/src/bank/bank-rec.db.test.ts`

## Open questions
- Resolved by RQ-0151 (route-scoped JSON limit, no multipart, no new dependency). If the chosen
  approach changes to multipart, ADR-0069 is required first.
