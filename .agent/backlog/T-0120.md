# T-0120 — Worker: run approved billing batches and deliver document email as jobs

## Goal
The worker runs `runBatch` (T-0044) when a batch is approved and delivers `ar.invoice.posted` email through `invoiceEmailHandler` (T-0042), so UC-01/UC-02 happen without a person calling functions.

## Context
- Approval (`POST /ar/batches/:id/approve`) writes an outbox event `ar.batch.approved`; a worker outbox handler calls runBatch with the worker's own db handle (per-item transactions).
- Queues are installed by lf_migrator (queue-admin.ts); the worker only consumes (ADR-0029 Proposed covers supervision).
- Email needs Chromium in the worker image (T-0119) and SMTP settings in compose (LF_SMTP_URL, LF_SMTP_FROM).

## Acceptance criteria
- [x] AC-1 Approving a batch over the API leads to all items posted by the worker (compose or db-integration with a real pg-boss runtime).
- [x] AC-2 A posted invoice event is delivered as one email by the worker handler; redelivery sends nothing more.
