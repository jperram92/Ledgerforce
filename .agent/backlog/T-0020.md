## Goal
journal_entry/journal_line per §3.3 with the deferred constraint trigger that rejects commit when Σdebit ≠ Σcredit, and exactly-one-side line check.

## Context (design refs)
- Design: §3.3 invariant 1; ADR-0004.
- Specs: — · Register: [success-scenarios.md](../../Docs/specs/success-scenarios.md)

## Open questions (→ research before start)
- None open. Re-read design §3.3, ADR-0004, ADR-0005 at claim. Found: numeric(19,4) rounds a 5th decimal on input (PostgreSQL typmod coercion), so the DB cannot refuse it without a type change. Recorded in DL-0074, carried to T-0025, with a domain-type proposal for the human.
