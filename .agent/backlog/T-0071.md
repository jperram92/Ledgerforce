# T-0071 — Sync issues inbox, retry/backoff and API-limit throttling

## Goal
Exponential backoff 1 min→6 h, then Sync issues inbox with payload and one-click retry; /limits throttle to 25% share.

## Report (T-0071, claude, round 8 worktree; branch feat/T-0071-sync-issues)

**Built**
- Migration 0030: `app.outbox_delivery_failure` (append-only log of failed attempts, secret-free
  summary), `app.sync_issue` (one per dead-lettered event + handler; status open / retried /
  resolved / ignored guarded by a trigger for every role; lf_app UPDATE on mutable columns only;
  never deleted), `salesforce_connection.api_budget_share` NUMERIC(5,4) default 0.2500,
  `app.permission_known` + `sync.issues.read` / `sync.issues.manage`. Both tables pass the
  generated cross-tenant suite (RLS ENABLE + FORCE, tenant_isolation, explicit grants).
- packages/outbox: `retryBounds`/`retrySchedule` (pg-boss formula as bounds), sync-issues store
  (failure log, `recordSyncIssue` idempotent per dead letter, list/get with payload, one-click
  `retrySyncIssue` as a new delivery job in the caller's transaction, `ignoreSyncIssue`,
  resolution of retried issues by `deliver`), `deliver` hook `onHandlerError`.
- apps/worker: outbox worker settles per job (`perJobResults`): completed / failed (retryable) /
  deadletter (permanent), output `{ handler, failureId }` only; dead-letter worker
  (`sync-issue-worker.ts`) records issues; `main.ts` starts it.
- apps/api: `GET /sync-issues` (status, keyset `after`, `limit`), `GET /sync-issues/:id`
  (payload), `POST /sync-issues/:id/retry`, `POST /sync-issues/:id/ignore` — permissions
  `sync.issues.read` / `sync.issues.manage`, audited, naturally idempotent; `main.ts` starts a
  runtime pg-boss for the requeue; nginx proxies `/sync-issues`.
- Salesforce write-back: handler always throttles (default gate), reads the connection's share,
  integer comparison in basis points; `getApiBudgetShare` / `setApiBudgetShare`.
- RQ-0044, ADR-0040 (Proposed, security, human gate), DL-0213..DL-0217; register SS-PLAT-25
  green, SS-PLAT-91/92 added green (totals 180 / 19).
