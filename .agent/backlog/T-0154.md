# T-0154 — UI: bank file (ABA) download and bank confirmation (follow-up of T-0087)

## Goal
UC-06 steps 3–4 on the payment batch screen built in T-0087: once a batch is released, a releaser
downloads the ABA (Cemtex) file (`POST /ap/payment-batches/:id/aba`, T-0056), and after the bank
has paid, records the bank's confirmation (`POST /ap/payment-batches/:id/confirm`, T-0057). The
screen shows the GP-009 journal that posts from the engine, never computed in the browser, and
the remittance advices that go out. Nothing on the screen shows an unmasked account number. The
file is a download only.

## Acceptance criteria (each maps to a test)
- AC-1 Given a released batch, when a releaser presses "Download the bank file", then the browser receives the `.aba` attachment and the screen notes it was made (audited by the API) → `tests/e2e/web/payment-batch.spec.ts`
- AC-2 Given a released batch, when the releaser records the confirmation date and bank reference, then the screen shows the posted GP-009 entry and the suppliers without a remittance contact (`remittance_missing`) → `tests/e2e/web/payment-batch.spec.ts`
- AC-3 Someone without `ap.payment_batch.release` sees neither action; refusals (422 NOT_CONFIRMABLE, 503 queue_not_configured) in plain words.

## Open questions
- Should the GP-009 journal be previewable before confirmation? There is no preview route for it today. Check T-0057 first and open an RQ if it is unclear.
