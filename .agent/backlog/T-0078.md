# T-0078 — Month-end close checklist (UC-10)

## Goal
Checklist: AR lock, AP lock, bank recs complete, accruals, TB review, soft close, hard lock after BAS; each step recorded with user/time; preconditions enforced.

## Context (design refs)
- Design: §3.5, UC-10.
- Specs: [UC-10](../../Docs/specs/UC-10.md) · Register: [success-scenarios.md](../../Docs/specs/success-scenarios.md)

## Acceptance criteria (each maps to a test + SS id)
- [ ] **SS-UC10-01** (db-integration) — Checklist steps recorded with user and time. *Given* period October; *when* the Finance Admin completes each step; *then* each step stores user, timestamp and resulting period status.
- [ ] **SS-UC10-02** (db-integration) — AR lock blocks AR posting except with override. *Given* October AR-locked; *when* an AR Clerk posts an October invoice, then an override user does; *then* the first is rejected; the second succeeds and is audited; AP bills still post.
- [ ] **SS-UC10-05** (db-integration) — Hard lock rejects or redirects per policy. *Given* October hard-locked; *when* a document dated October is posted under each lock policy; *then* "reject" → PERIOD_LOCKED; "first open date" → dated 2026-11-01 with note.
- [ ] **SS-UC10-07** (db-integration) — Close cannot pass with unreconciled bank. *Given* an unreconciled October bank line; *when* the "bank recs complete" step is marked; *then* the step is refused, listing the account.
- [ ] **SS-UC10-08** (db-integration) — TB review step shows TB nets to zero. *Given* October postings; *when* the TB review step runs; *then* total debits = total credits and AR/AP subledgers = controls.
