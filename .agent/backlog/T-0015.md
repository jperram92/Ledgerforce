# T-0015 — Segregation-of-duties engine and small-team mode

## Goal
Rules 1–6 of §6.5 evaluated centrally with configurable thresholds; small-team mode allows the action only with an external reviewer or a recorded exception on a weekly report.

## Acceptance criteria (each maps to a test + SS id)
- [ ] **SS-UC05-05** (db-integration) — SoD: clerk cannot approve own bill above $1,000. *Given* a $2,750 bill entered by user A; *when* user A approves it; *then* approval is denied with SOD_BILL_SELF_APPROVAL and audited.
- [ ] **SS-UC05-06** (db-integration) — Small-team mode records a visible exception. *Given* small-team mode and a single user; *when* the user approves their own bill; *then* approval succeeds only with a recorded exception that appears on the weekly review report.
- [ ] **SS-UC06-02** (db-integration) — Creator cannot release own batch. *Given* the SS-UC06-01 batch created by user A; *when* user A releases it; *then* release is denied with SOD_BATCH_SELF_RELEASE.

- [ ] **SS-PLAT-16** (unit) — SoD rules 1–6 evaluated as configured. *Given* table of actor/action/subject cases incl. small-team mode; *when* the SoD engine evaluates them; *then* results equal the expected table.
