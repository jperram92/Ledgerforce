# T-0015 — Segregation-of-duties engine and small-team mode

## Goal
Rules 1–6 of §6.5 evaluated centrally with configurable thresholds; small-team mode allows the action only with an external reviewer or a recorded exception on a weekly report.

## Context (design refs)
- Design: §6.5; §11.2 SoD thresholds are an open human decision — defaults are placeholders.
- Specs: [UC-05](../../Docs/specs/UC-05.md), [UC-06](../../Docs/specs/UC-06.md), [UC-11](../../Docs/specs/UC-11.md) · Register: [success-scenarios.md](../../Docs/specs/success-scenarios.md)
