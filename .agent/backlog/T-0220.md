# T-0220 — Failed security notices are noticed without opening Settings

## Goal
T-0209 puts failed security notices on Settings → Failed security notices. An administrator only
sees them if they open that page. Show a count (Settings section or the Timeline) to holders of
`security_notices.read` when any notice is failing, without a new permission and without
polling more than the shell already does.

## Acceptance criteria
- [ ] AC-1 (API) a cheap count of failing notices for `security_notices.read` holders
- [ ] AC-2 (e2e) the count is shown, with a link to the list, and is absent at zero, with screenshots
