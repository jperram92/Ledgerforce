# T-0159 — Deprecate the ECL allowance setting in the schema (follow-up to T-0145, ADR-0068)

## Goal
ADR-0068 made AR_ECL_ALLOWANCE the single source. This card records the deprecation in the database and cleans up the template:
- add `COMMENT ON COLUMN app.ar_settings.ecl_allowance_account_id`, in the next migration the lead owns (forward-only, nothing dropped);
- remove the template's `ecl_allowance_account` suggested setting, keeping the role binding.

- [ ] AC-1: A migration test reads the column comment ("deprecated: AR_ECL_ALLOWANCE role is the source, ADR-0068").
- [ ] AC-2: templates.test.ts shows no suggested setting for the ECL allowance, and the role binding still loads.
