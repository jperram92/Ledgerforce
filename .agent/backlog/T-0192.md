# T-0192 — Rotate the session id on step-up

## Goal
RQ-0165 noted that OWASP ASVS 5.0 requirement 7.2.4 (Level 1) asks for a new session token on re-authentication, while ADR-0025 keeps the session id on step-up. Decide (security ADR superseding the relevant part of ADR-0025, decided by the building agent under DL-0691 with research) and implement rotation: on a successful step-up the old session id stops working and the browser gets a new `lf_session` cookie, with no loss of the user's work.

## Acceptance criteria
- [x] AC-1 (api-db) after step-up the old session cookie is refused and the new one works with the fresh step-up time
- [x] AC-2 (api-db) a concurrent request with the old cookie during rotation fails closed (401), never with elevated rights
- [x] AC-3 (e2e) the StepUpPrompt flow keeps the user on the same screen and the retried action succeeds
