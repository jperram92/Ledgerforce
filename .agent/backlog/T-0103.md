# T-0103 — Conductor: Windows provider process-tree termination on missed heartbeat

## Goal
On Windows (Git Bash), when a provider misses its heartbeat, the conductor terminates the
whole provider process tree within the existing deadline so `run` can fail over. Linux and
macOS behaviour is unchanged.

## Context (design refs)
- Design §10.4 (lease, heartbeat and failover); DL-0059, DL-0060; RQ-0014.
- Split out of T-0010 step 10 on 2026-10-24 by claude: it is conductor tooling, not tenancy, and
  reproduces only on Windows. On Linux, `node --test scripts/agent/test/` passes, including
  "missed heartbeat".
- Codex finding (run 2026-10-24-codex-r01): the original provider PID disappears while
  descendants keep the pipes open; `taskkill /T /F` on the spawned PID returns "not found".

## Open questions (→ research before start)
- [x] How to own the whole tree on Windows: a Job Object (via a tiny helper), `detached` plus
  process groups, or tracking descendants by parent PID, within DL-0005 zero-dependency limits.
