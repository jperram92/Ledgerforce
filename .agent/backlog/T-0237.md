# T-0237 — Bills mailbox settings API and screen

## Goal
Split from T-0216 (DL-0930). Let an administrator see and manage how bills reach the company
from Settings: the inbound address (T-0215) with a step-up "rotate", an IMAP mailbox with a
password (T-0127 `saveBillsMailbox`), "Connect with Microsoft / Google" buttons using T-0216's
`POST /setup/bills-mailbox/oauth/start`, a "Test connection" action, and the mailbox's status
(last poll, fixed error class, "Reconnect" when an OAuth mailbox shows auth_failed).

## Acceptance criteria
- [ ] AC-1 (api-db) `GET /setup/bills-mailbox?company_id=` (settings.read): mailboxes (no
  secret: auth_method, provider, host, user, folder, status, last error) and the inbound
  address; `PUT` a password mailbox (settings.setup.manage + step-up 300 s + Idempotency-Key,
  audited without secret; supersedes the active row) → `apps/api/src/ap/bills-mailbox.db.test.ts`
- [ ] AC-2 (api-db) "Test connection" reports the fixed ADR-0095 error class against the fake
  IMAP server (password and OAuth rows) → same file
- [ ] AC-3 (api-db) rotate the inbound address (settings.setup.manage + step-up, audited, old
  address stops routing) → same file
- [ ] AC-4 (web + Playwright) Settings → Bills mailbox screen, all states (no mailbox, password,
  OAuth connected, auth_failed → Reconnect, callback `?mailbox=connected` / `?mailbox_error=`),
  screenshots as evidence (SS-PLAT family)
