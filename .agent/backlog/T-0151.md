# T-0151 — AR cash API for the T-0085 screens (split from T-0085)

## Goal
The data side the receipt allocation screen (SS-UC03-10) and the credit-note screen (SS-UC11-08)
need, which did not exist (DL-0490):
- `listReceipts` (@ledgerforce/ar) and `GET /ar/receipts?company_id=&unallocated=true` (ar.read):
  each receipt with its party and what is still unallocated (the receipt's own AR open item).
- `POST /ar/receipts/:id/allocations` now requires an **Idempotency-Key** (apps/api rule: every
  mutating route; before, a retry allocated again) and replays on a repeat; a receipt outside the
  tenant/company is 404 (`RECEIPT_NOT_FOUND`).
- `previewCreditNoteJournal` and `GET /ar/credit-notes/:id/journal` (ar.read): the posting
  engine's `preview()` of exactly what `approveCreditNote` posts (GP-005), through one shared
  builder; writes nothing. Not in the company → 404; not a draft → 422 NOT_DRAFT.
