# T-0202 — Opening balances screen: foreign-currency items

## Goal
T-0126 (GP-043, ADR-0088, DL-0744) lets the open-item CSV carry `currency`, `currency_amount` and
`fx_rate`, and the API returns them on preview lines (`txn_currency`, `txn_amount`, `fx_rate`) and
items. The T-0177 screen (SS-PLAT-132) does not show them yet. Show them in the journal preview and
posted view, and explain on the screen that the base amount is the old system's carrying amount
(revalue in the old system first when the balance date is a reporting date, ADR-0088 consequences).

## Acceptance criteria
- [ ] AC-1 (e2e, 1440 and 390) a USD item's preview line shows "USD 1,000.00 @ 1.53846154" beside
  its AUD amount; base lines show no rate
- [ ] AC-2 (e2e) an FX_MISMATCH refusal names the CSV line in plain words
- [ ] AC-3 (web unit) the CSV help lists the three optional columns
