# T-0106 — Timeline design system: component fixes and @ledgerforce/ui package

## Goal
Turn the chosen prototype (Docs/ui/system, DL-0070) into a tested React component package
`packages/ui` that apps/web builds every screen from. It contains tokens, `Money` (P3), `Lane` and
`Axis` (timeline), `Spine` (document life story), `TurnQueue` (Direction A's list pattern, P13) and
`JournalTable` (Dr/Cr with plain glosses, P12). It also closes the fixes the recommendation lists
as owed before build.

## Context (design refs)
- Docs/ui/system/README.md, Docs/ui/principles.md v1 (P1–P15), Docs/ui/research/03-recommendation.md §2.
- Stack (design §7.1): React + shadcn/ui. Use shadcn/Radix primitives for accessibility, restyled
  with Timeline tokens only. Never the default shadcn theme, which the checklist flags as generic (G-items, RQ-0084).
- Created 2026-10-24 by claude after the product owner chose C (DL-0070).
