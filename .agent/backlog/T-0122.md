# T-0122 — Customer refund via Stripe refund API

> **Superseded by T-0074** (DL-0305). SS-UC11-04 was built in T-0074 on
> `feat/T-0074-stripe-webhooks` (`refundCreditViaStripe`, GP-006 Stripe variant, DL-0287). This card
> is kept for history only; do not claim it.

## Goal
Refund a customer credit to the card it was paid with: a `customer_refund` with method `stripe`
(T-0055 already reserves the value in the `method` CHECK, migration 0049) calls the Stripe refund
API against the original charge and posts the GP-006 Stripe variant (line 2 =
`setting:stripe.clearing_account`, 1120; the refund nets in the next payout). Split from T-0055
(DL-0305): it needs `@ledgerforce/connector-stripe`, which is built on
`feat/T-0073-stripe-payment-links` and is not integrated with the payment-batch line yet.
