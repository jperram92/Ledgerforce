# T-0185 — Bank accounts screen (wizard step 4)

## Goal
Split from T-0176 (DL-0640). An Owner or Finance Admin lists the company's bank accounts (account
numbers masked to the last 3 digits, design §6.6) and adds one, choosing the GL bank account it
posts to and entering the APCA user id and ABA user name that batch payment files need, so the
wizard's step 4 missing list empties. Adding follows the bank module's rules
(`createCompanyBankAccount`: sealed number, BSB, BECS user name); without a key service the route
answers 503 `kms_not_configured` (ADR-0030).

## Context (design refs)
- Design §4.1 step 4, §6.6; RQ-0161; ADR-0081 (route family; this card adds its routes to it).
- `packages/modules/bank/src/bank-accounts.ts`; validator `packages/modules/setup/src/wizard-validators.ts` (bank).
- T-0180 (remittance account designation) touches the same accounts: coordinate, do not overlap.

## Acceptance criteria (each maps to a test + SS id)
- [x] **AC-1** — `GET /setup/bank-accounts` (settings.read, masked) and `POST /setup/bank-accounts` (settings.setup.manage, Idempotency-Key with a replay record that needs no migration, audited with the masked number) → `apps/api/src/setup/bank-accounts-settings.db.test.ts`.
- [x] **AC-2** — SS-PLAT-130: the screen lists masked accounts, adds one, links from wizard step 4; read-only without settings.setup.manage; forbidden without settings.read; refusals in plain words → `tests/e2e/web/settings-bank-accounts.spec.ts` (1440 and 390, axe, genericness probe).

## Open questions (→ research before start)
- Replay of a create without a migration: is (company, name) unique, or does the key need a store? Answer in RQ-0161 follow-up or a new RQ before in_progress.
  **Answered (RQ-0166, ADR-0084, DL-0700..DL-0704):** (company, name) is not unique, but the
  database allows one active bank account per GL account; that account is the replay record
  (same selected fields → 200 `replayed:true`, otherwise 409 `GL_ACCOUNT_IN_USE`). No migration.
  The add also needs step-up 300 s (DL-0701), no SoD step.
